# Reusable AI Start Prompt

Copy this prompt into a new AI conversation when continuing Zayan Hardware:

```text
أنت تكمّل تطوير مشروع Zayan Hardware الحالي، وليس مطلوبًا منك بناء مشروع جديد.

قبل أي تعديل، اقرأ بالترتيب:
1. AGENTS.md
2. AI_CONTEXT.md
3. docs/CURRENT_STATE.md
4. UPDATES.md
5. README.md
ثم افتح docs/architecture-code-map.md والتوثيق الخاص بالميزة المطلوبة، وبعدها افحص الكود الفعلي في الفرع الحالي.

تحقق من git status والفرع والـ commit الحالي. لا تفترض أن GitHub main أو أي PR أو نسخة XAMPP المحلية أو قاعدة البيانات تمثل نفس الحالة. حافظ على كل التعديلات المحلية والملفات غير المتتبعة.

نفّذ الميزة المطلوبة فقط، ووسّع فهمك للملفات المرتبطة بها بالقدر اللازم. التزم ببنية PHP MVC الحالية، ولا تعِد كتابة أو تستبدل نظامًا موجودًا قبل فهمه وإثبات الحاجة. تجنّب التعديلات الجانبية والـ refactoring غير المطلوب.

حافظ على المنشورات والردود والتقارير الفنية والمخططات والمرفقات وسجل التعديلات ونسب المساهمات؛ ممنوع حذفها فعليًا بسبب حذف حساب أو تعديل عادي. لا تنفذ عمليات مدمرة على قاعدة البيانات أو الملفات الحقيقية دون موافقة صريحة ونسخة احتياطية قابلة للاستعادة وخطة رجوع.

بعد التنفيذ: شغّل الاختبارات المركّزة المناسبة، وحدّث UPDATES.md وdocs/CURRENT_STATE.md والتوثيق المتخصص، وحدّث README.md عند الحاجة. اذكر الملفات التي تغيرت والاختبارات التي نُفذت ونتائجها وأي خطوات يدوية أو نقاط لم يتم التحقق منها. لا تدّعِ نجاح اختبار أو نشر لم يحدث فعليًا.

الأولوية الحالية هي استكمال المميزات المطلوبة؛ لا تبدأ تدقيقًا شاملًا أو إعادة بناء أو Graphify شاملًا إلا إذا طلب المالك ذلك صراحةً. ابدأ الآن بتحديد الملفات والتبعيات المرتبطة بالميزة التي سأطلبها منك.
```

This prompt is intentionally short. The repository instructions and documentation are the actual source of truth; the prompt only points the AI to them.
